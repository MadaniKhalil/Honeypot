HONEYPOT NOTES - STEP 1: LISTENER

socket()
- sockaddr_in = IPv4 specific struct, from netinet/in.h
- zero out the struct so it has no garbage values (can cause bugs)
- void *memset(void *ptr, int value, size_t size)

Building the address
- sin_family = AF_INET, sin_port = htons(2323), sin_addr.s_addr = htonl(INADDR_LOOPBACK)
- INADDR_LOOPBACK = 127.0.0.1 = "only this machine"
- htonl = host to network, long (32-bit). IP address is 32 bits.
- sin_addr is itself a struct, s_addr is the field inside it
- Meaning of the last line: listen only for visitors from inside this machine

bind()
- bind() takes the generic sockaddr pointer (accepts IPv4, IPv6, Unix sockets)
- so the second parameter is cast to struct sockaddr
- if socket opens -> bind fails -> return 1 -> socket stays open
- solution: close the socket on failure, like freeing memory
- HABIT: LEARN SAFETY

listen()
- args: int socket_fd, int backlog
- backlog = limit of connections waiting in the queue before you accept() them
- if listen() fails and we never close(): nothing bad happens, kernel closes every fd on exit
- still a good habit, like free()
- after listen(): socket is created, bound to a full address (family, port, IP), and waiting
- test: pause with getchar(), nc 127.0.0.1 2323, kernel completes the handshake and queues the visitor

accept()
- accept() takes the listening fd and gives back a NEW fd = connection_fd
- listen_fd keeps listening, connection_fd is for this one visitor
- new_addr (sockaddr_storage) = where the visitor's address goes, big enough for IPv4 or IPv6
- newaddr_size must be set to sizeof new_addr BEFORE the call
- accept() blocks until a visitor arrives, -1 = error
- no accept() = visitor stuck in queue, CLOSE-WAIT after nc quits
- close both fds at the end
- test: ./trap (blocks), nc 127.0.0.1 2323 -> prints "connected", exit 0
